# StreamDock Zabbix

Универсальный плагин для LCD-клавиш StreamDock / HotSpot. Получает значения и цвета непосредственно из виджетов **«Значение элемента данных»** (Item value) Zabbix.

[English README](README.md)

## Возможности

- **Для каждой кнопки отдельно:** выбор доступного Dashboard из списка или ввод ID вручную.
- Выбор страницы Dashboard и нужного виджета из выпадающего списка.
- Видны имя виджета, хост, название элемента данных и ID виджета.
- Необязательная собственная подпись.
- Числовые значения или статусы и цвета по порогам, установленным в самом Zabbix.
- Опрос значений каждые **5 секунд**, перечитывание структуры Dashboard каждые **60 секунд**.
- Нажатие клавиши открывает соответствующий Dashboard.
- Нет данных / элемент отключён или не поддерживается: серый цвет, без ложного зелёного статуса.
- Общий локальный мост к Zabbix без паролей в настройках кнопок.
- Защита пароля или API-токена средствами Windows DPAPI.
- Установка только для текущего пользователя, автозагрузка и безопасное удаление.

Плагин независимый, не является официальным продуктом Zabbix или производителя устройства.

## Требования

- Windows 10/11.
- Программа HotSpot/StreamDock с поддержкой .sdPlugin (SDK v1, HotSpot 2.9+).
- Python **3.9 или новее** с pythonw.exe в PATH (python / py -3).
- Доступ к серверу Zabbix через HTTPS, проверено на Zabbix 7.0.
- Учётная запись только для чтения, имеющая доступ к Dashboard и элементам данных (методы dashboard.get и item.get).
- Дополнительные библиотеки Python не требуются.

## Установка

Распакуйте архив релиза в произвольную папку. Откройте PowerShell в этой папке и выполните:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\configure.ps1

При настройке укажите URL своего Zabbix, логин и пароль. Ввод пароля скрыт, в командной строке или конфигурации кнопок он не хранится.

**Для входа через API-токен**, вместо обычной авторизации:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\configure.ps1 -UseToken

Перезапустите HotSpot, чтобы программа обнаружила новый плагин.

Установщик помещает файлы в:

    %LOCALAPPDATA%\StreamDock-Zabbix
    %APPDATA%\HotSpot\StreamDock\plugins\com.streamdock.zabbix.sdPlugin

Пароль хранится только в локальном зашифрованном файле credentials.dpapi, привязанном к текущему пользователю Windows.

### Настройка LCD-кнопки

1. В HotSpot перетащите действие **Monitoring → Zabbix: Item widget** на кнопку.
2. Выберите **Dashboard** в списке. Также можно ввести его ID вручную и нажать **Открыть**.
3. Выберите страницу Dashboard.
4. Выберите виджет типа **«Значение элемента данных»**.
5. Укажите подпись, если нужна своя.
6. Нажмите **Сохранить выбор**.

Система сохраняет ID Dashboard, страницы и виджета **отдельно в настройках каждой кнопки**. Можно одновременно использовать совершенно разные Dashboard.

Некоторые виджеты в Zabbix используют динамическую подстановку хоста и не содержат собственного itemid в ответе API. Они отображаются в списке как **без привязки** и недоступны для выбора: подставлять произвольный элемент было бы некорректно.

### Проверка подключения

    Invoke-RestMethod http://127.0.0.1:18398/health

- **running: true** — локальный мост запущен.
- **connected: true** — авторизация и доступ к API Zabbix успешны.

Мост слушает только 127.0.0.1:18398 и не публикуется в корпоративную или внешнюю сеть.

### Обновление и повторная установка

Для обновления повторно выполните:

    .\install.ps1

Существующие settings.json и credentials.dpapi не перезаписываются. Установка поддерживает запуск из любой папки и проверяет случай, когда файл-источник совпадает с файлом назначения.

Для тестовой установки без запуска и автозагрузки:

    .\install.ps1 -InstallPath "$env:TEMP\ZabbixTest" -PluginPath "$env:TEMP\HotSpotTest" -NoStart -NoAutostart

### Удаление

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1

Настройки и зашифрованные учётные данные по умолчанию сохраняются. Для полного удаления:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1 -PurgeUserData

Другие плагины и профили HotSpot не удаляются.

## Разработка и тесты

Серверная часть состоит только из стандартной библиотеки Python. Компоненты находятся в src/, графический интерфейс плагина — в plugin/com.streamdock.zabbix.sdPlugin/.

Проверить локально:

    python -m unittest discover -s tests -v
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\install_smoke.ps1
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\configure_smoke.ps1
    node --check .\plugin\com.streamdock.zabbix.sdPlugin\plugin.js
    node --check .\plugin\com.streamdock.zabbix.sdPlugin\inspector.js

Тесты также запускаются в GitHub Actions на Windows.

## Безопасность

- В опубликованных файлах нет корпоративного Zabbix-адреса, названий организаций, логинов, паролей, локальных профилей и экспортов конфигурации.
- Пароль не попадает в профиль HotSpot, JavaScript или API-адреса.
- Токены и логины храните только в файле credentials.dpapi в пользовательском каталоге Windows.
- Не публикуйте свой settings.json, *.dpapi, логи или экспортированные профили.
- HTTPS использует обычную проверку сертификата, обхода верификации в проекте нет.
- Не открывайте TCP-порт 18398 для удалённого доступа.

## Сборка релиза для GitHub

После проверки исходников:

    git add -A
    python scripts/build_release.py

Сборщик включает только файлы, добавленные в Git, и создаёт ZIP с контрольной суммой SHA-256 в папке dist/. Локальная конфигурация, файлы DPAPI и экспортированные профили не включаются в архив.
