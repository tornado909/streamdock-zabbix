# Changelog

## 1.0.0 - Initial public release candidate

- Generic Dashboard / page / Item value widget picker.
- Optional manual Dashboard ID.
- Independent per-key selection and custom label.
- Colors and numeric values synchronized with Zabbix widget thresholds.
- Local read-only API and Windows DPAPI credential storage.
- Repeatable installer, configuration assistant and safe uninstaller.
- Standalone unit tests and Windows installer smoke tests.
- Generic sample configuration with no organizational data.
